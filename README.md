# Soda — hero-лендинг Diet Soda

Один файл `index.html`, без сборки. Собран по готовому ТЗ (2026-10-25).

## Что внутри
- Полноэкранный hero без скролла, радиальный фон: бирюзовый (Classic) / синий (Zero Lime).
- 3D-банка (`<model-viewer>`) наклоняется за курсором.
- 13 плавающих 3D-моделей (вишни, листья) с параллаксом и отталкиванием от курсора.
- Пузыри (PNG) поднимаются снизу каждые 400 мс.
- Клик по карточке вкуса: фон меняет цвет, банка крутится на 720° с размытием и меняет текстуру, ягоды схлопываются к центру, меняются на чернику/вишню и разлетаются.

## Зависимости (CDN)
GSAP 3.12.2, Google `model-viewer`, шрифты Google Fonts (Galada, Inter, Manrope).

## Ресурсы
3D-модели, текстуры и PNG загружаются с `api.getlayers.ai` — нужен интернет. Локальных копий нет.

## Не проверено
Визуально в браузере не открывали: страница зависит от внешних ресурсов.
